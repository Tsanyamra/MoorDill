MoorDill ensures high-availability, real-time processing of complex data streams in a horizontally scalable service cluster.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/MoorDill.git`
2. `cd MoorDill`
3. Install in editable mode: `pip install -e .`

## Configuration

MoorDill is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
